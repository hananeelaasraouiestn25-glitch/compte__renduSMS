# 📱 TP – Envoyer un SMS (Android)

## 📚 Contenu du TP

**Exercice : Envoyer un SMS**

Créer une application Android qui permet d'envoyer un SMS à partir d'un numéro et d'un message, avec la classe `SmsManager`.

- Interface graphique en XML (`TextView`, `EditText`, `Button`)
- Vérification des entrées (numéro et message)
- Messages `Toast` de confirmation ou d'erreur
- Permission `SEND_SMS` dans `AndroidManifest.xml`

## 🚀 Installation

1. Télécharger ou cloner le projet.
2. Ouvrir le projet avec Android Studio.
3. Attendre la synchronisation de Gradle.
4. Exécuter l'application sur un émulateur ou un appareil Android.

> Sur Android 6.0 et plus, autoriser les SMS dans Paramètres > Applications > sms > Autorisations.
